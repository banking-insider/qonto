# Qonto Business Account 2026 — Fees, Features and Welcome Offers

Independent editorial website, built as a standalone static page for GitHub Pages.

## Important: why the previous version appeared without styling

The previous version linked to `assets/styles.css`. If the `assets` folder was not uploaded or GitHub Pages had not deployed it, the page displayed unstyled HTML. **This version embeds the full CSS directly inside `index.html`**, while also keeping `assets/styles.css` for editing. The page remains styled even if the external stylesheet cannot load.

## Upload to GitHub Pages

1. Extract the ZIP. Upload **all files and the entire `assets` folder** to the root of `banking-insider/qonto`.
2. Keep `.nojekyll` (a hidden file) and `index.html` at the root, not inside another folder.
3. Commit the changes. In Settings → Pages select Deploy from a branch, `main`, `/(root)`.
4. Open `https://banking-insider.github.io/qonto/` and hard-refresh if an old version is cached.
5. Test `https://banking-insider.github.io/qonto/assets/styles.css` directly. It should show CSS, not a 404.
